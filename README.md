# season-badges

**어느 페이지에든 붙이는 봄 · 여름 · 가을 · 겨울 배지 네 개.**
누르면 그 계절 날씨로 바뀝니다. 겨울은 눈이 내려 쌓이고, 봄은 나무가 자라 꽃이 피고, 여름은 햇볕과 풀, 가을은 낙엽.

- 파일 하나(`seasons.js`)가 전부입니다. 설치할 것도, 서버도 없습니다.
- 내가 만든 페이지에 붙여도 되고, 북마클릿으로 구글 같은 남의 페이지에 잠깐 얹어도 됩니다.
- 코드를 몰라도 됩니다. Claude 에게 부탁하면 됩니다.
- 시연: `index.html` 을 더블클릭해 보세요.

## 코드를 몰라도: Claude 에게 부탁하기

### 방법 1. Claude Code (컴퓨터에 설치한 Claude)

1. 이 저장소를 내려받습니다. 초록색 **Code** 단추 → **Download ZIP** → 압축을 풉니다.
2. **내 페이지가 있는 폴더**에서 Claude Code 를 엽니다.
3. 이렇게 말합니다.

```
<내려받은 season-badges 폴더 경로>/SKILL.md 대로 내 페이지에 계절 배지를 붙여 줘.
```

### 방법 2. claude.ai 대화창

1. `seasons.js` · `SKILL.md` · 내 페이지 파일(`index.html` 등)을 대화창에 올립니다.
2. 「SKILL.md 대로 내 페이지에 계절 배지를 붙여서 파일로 돌려줘」 라고 말합니다.
3. 받은 파일과 `seasons.js` 를 같은 폴더에 두고 엽니다.

## 손으로 하기

`seasons.js` 를 내 페이지 옆에 두고 `</body>` 앞에 한 줄.

```html
<script src="seasons.js" defer></script>
```

배지를 놓을 자리가 있으면 그 자리에(없으면 왼쪽 아래에 뜹니다).

```html
<span data-season-badges></span>
```

| 붙일 수 있는 것 | 뜻 |
|---|---|
| `data-tint="off"` | 페이지 전체를 옅게 물들이는 막을 끔(페이지가 스스로 색을 바꿀 때) |
| `data-default="winter"` | 처음부터 그 계절로 |
| `data-lang="en"` | 배지 글자를 영어로 |
| `data-compact` | 글자 없이 그림만 |

### 내 페이지 색까지 바꾸기

배지를 누르면 `<html data-season="winter">` 처럼 붙습니다. CSS 에서 고르면 됩니다.

```css
html[data-season="winter"] { --bg: #e6eef6; --text: #1d3247; }
```

## 구글 같은 남의 페이지에 얹기 (북마클릿)

1. `index.html` 을 크롬 · 엣지 · 웨일로 엽니다.
2. 「✳ 계절 배지」 단추를 **북마크바로 끌어다 놓습니다.**
3. 아무 페이지에서 그 북마크를 누르면 왼쪽 아래에 배지가 뜹니다. 한 번 더 누르거나 × 로 닫습니다.

그 페이지에 잠깐 얹을 뿐 사이트를 바꾸지 않습니다. 새로 고치면 사라집니다. 폰 브라우저는 북마클릿이 불편해서 컴퓨터를 권합니다.

## 알아 둘 것

- 날씨 그림은 페이지 위에 얹은 투명한 그림판입니다. 클릭은 그대로 아래로 지나갑니다.
- 배지 자리에는 그림이 비켜 갑니다.
- 움직임 줄이기를 켠 기기에서는 멈춘 한 장으로 나옵니다.
- 고른 계절은 그 브라우저에 기억됩니다(내 페이지에 붙인 경우).
