01내 페이지에 붙이기

Claude 에게 이렇게 말하면 됩니다.

season-badges 의 SKILL.md 대로 내 페이지에 계절 배지를 붙여 줘.

손으로 하려면 seasons.js 를 내 페이지 옆에 두고 맨 아래에 한 줄. 배지 놓을 자리가 있으면 그 자리에 <span data-season-badges></span>.

<script src="seasons.js" defer></script>

02네이버 · 구글 같은 남의 페이지에 얹기

  1. 1
    키보드에서 Ctrl + Shift + B 를 누르세요. (맥은 ⌘ + Shift + B)
    주소창 바로 아래에 북마크바(가는 줄)가 생겨요.
  2. 2
    아래 단추를 잡고, 위쪽 북마크바로 끌어 올리세요.
    4계절 배지 ↑ 북마크바로
  3. 3
    네이버 · 구글 등 아무 사이트로 가서, 북마크바에 생긴 「4계절 배지」 를 누르세요.
  4. 4
    화면 위 가운데에 뜬 배지에서 계절을 고르세요.
    왼쪽 손잡이(⠿)를 잡고 끌면 자리를 옮기고, × 로 닫아요. 새로 고치면 사라져요.

그 페이지에 잠깐 얹을 뿐 사이트를 바꾸지 않아요. 컴퓨터 브라우저(크롬 · 엣지 · 웨일)에서 됩니다.

북마크 대신 크롬 확장으로 (아이콘 한 번)
  1. 저장소에서 ZIP 을 내려받아 풉니다.
  2. 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기 → 압축해제된 확장 프로그램을 로드합니다 → 푼 폴더 안의 extension 폴더.
  3. 오른쪽 위 퍼즐 조각 → 「계절 배지」 옆 핀. 이제 아무 페이지에서 ✳ 아이콘을 누르면 배지가 뜹니다.

03link-cards 와 같이

link-cards(링크를 카드로 모아 주는 한 장짜리 페이지)에는 머리에 배지 자리가 이미 있습니다. seasons.js 를 옆에 두면 켜지고, 지우면 배지만 사라집니다.
